# 考試答案卷與解答卷產生器

產出兩份**幾何完全一致**的單頁文件（預設 JIS B4 257×364 mm）：

| 文件 | 內容 |
|---|---|
| 學生答案卷 | 標題、班級/學號/姓名/得分欄、填空題「題號＋答案格」表格、問答題空白作答框 |
| 解答卷 | 同一版面；填空答案以紅字印在**題號格**、答案格留白（挖空後疊在學生卷上比對）；問答題框內印出完整解題過程 |

另附：題目卷縮頁轉 PDF 工具、作答時間估計方法。

## 需要的工具

`python-docx`、LibreOffice（`soffice`，轉 PDF）、`poppler-utils`（`pdfinfo`/`pdftoppm`/`pdftotext`）、`Pillow`、`numpy`。

```
scripts/make_answer_sheets.py   設定檔 → 學生卷 + 解答卷 (.docx，可加 --pdf)
scripts/verify_sheets.py        驗證：單頁、紙張尺寸、填空區格線位置兩份一致
scripts/fit_question_pdf.py     題目卷 .docx → 不超過 N 頁的 PDF（自動選最大字級）
examples/115-cs-intro-midterm.json   完整範例設定（35 題填空 + 3 題問答）
```

## 工作流程

### 1. 讀試題、整理答案

- 用 `pandoc -t plain` 或 python-docx 讀出所有題目，確認題型、題數、配分。
- **檔名寫「含答案」不代表真的有答案**——先檢查（也看紅字、隱藏文字）。沒有答案就自己解，並用 Python 驗算所有數值題（進位轉換、IEEE 754、位元運算、2 補數等）。
- 文字題（例如「程式／program」「非揮發性／nonvolatile」）提醒老師自行決定可接受的同義答案。

### 2. 寫設定檔

複製 `examples/115-cs-intro-midterm.json` 修改。重點欄位：

| 欄位 | 說明 |
|---|---|
| `title` / `key_title_suffix` | 標題；解答卷在標題後加「（解答）」 |
| `paper` | 紙張與邊界（mm）。台灣說的 B4 通常是 JIS 257×364 |
| `id_fields` / `id_widths_mm` | 預設班級、學號、姓名；`score_box` 是否加得分格 |
| `fill_in.count` / `columns` / `row_height_mm` | 填空題數、欄數（直式編號：先排滿第一欄）、列高 |
| `fill_in.num_width_mm` | 題號格寬度。解答要印在這格，**至少 34 mm**（約可放 7～8 個中文字的答案） |
| `fill_in.answers` | `{"題號": "答案"}`；支援 `_{下標}`、`^{上標}`，例如 `2^{31} − 1` |
| `written.layout` | 問答框排法：`columns_mm` 為各欄寬度比例，`columns` 為每欄由上而下的題目與高度權重 `weight` |
| `written.questions[].key` | 解答段落 `[種類, 文字]`：`p` 一般、`h` 粗體小標、`m` 等寬字（直式位元運算對齊用） |

問答區高度會自動算成「頁面剩下的空間」，再依 `weight` 分配。

**作答空間估算**：手寫一行約 7 mm 高。逐題估計學生需要幾行（例如 IEEE 754 轉換約 12 行、四小題位元運算約 15 行），可用空間最好是需求的 1.5～2 倍。程式最後會印出問答區高度；不夠就減少填空列高（不低於 9 mm）或調整欄寬比例。

### 3. 產生並驗證

```bash
python3 scripts/make_answer_sheets.py config.json OUT_DIR --pdf
python3 scripts/verify_sheets.py config.json OUT_DIR/學生卷.pdf OUT_DIR/學生卷_解答.pdf
```

驗證通過後，仍要把兩份 PDF 轉成圖片**用眼睛看一遍**：解答文字有沒有被固定列高切掉、長答案是否換行、問答解答是否超出框。

### 4. 交付與列印提醒（告訴老師）

- 交付 .docx（可編輯）＋ .pdf（列印用）。
- 若轉檔環境沒有標楷體，PDF 會用替代字型，版面不受影響。要標楷體就請老師在自己電腦用 Word「另存 PDF」。
- **疊合比對的條件**：兩份用同一台印表機、同一種紙、同一個縮放設定（建議「實際大小」）。只要其中一份縮到 97%，填空表格到最後一列就會錯開約 3.5 mm。大量印之前先各印一張疊看看。
- ISO B4（250×353）比 JIS B4 小 7×11 mm：印 PDF 時選置中或「縮小過大的頁面」仍印得完整。**不要在 Word 裡把紙張改成 ISO B4**，固定高度的版面會被擠到第二頁。

### 5. 題目卷轉成指定頁數的 PDF（老師要求時）

```bash
python3 scripts/fit_question_pdf.py 題目.docx 題目卷.pdf --pages 2 [--max-pt 16] [--keep-from 二、]
```

程式會從原字級往下每次減 0.5pt，挑出「頁數符合、沒有缺字、底線空格沒被拆開」的最大字級，原 .docx 不會被改動。選好後一樣要看圖確認，例如有沒有題目被拆在兩頁之間；有的話可用 `--max-pt` 壓低一級再試。

輸出檔名用「題目卷」，不要沿用「題庫(含答案)」之類會讓人誤會的名稱。

### 6. 作答時間估計（不用計算機）

逐題分類估算，給範圍與建議時間：

| 題型 | 每題估計 |
|---|---|
| 概念記憶填空 | 0.5～1 分 |
| 進位轉換、位元運算等計算填空 | 1～2.5 分（含小數的轉換、多位數乘法最費時） |
| IEEE 754 單精度轉換 | 8～12 分 |
| 多小題位元運算／移位說明 | 8～12 分 |
| 短計算題（例如 I/O 定址） | 3～5 分 |

加總給「一般學生約 X 分鐘」，建議考試時間再加 15～25 分鐘檢查。範例考卷：約 50～80 分鐘，建議 90 分鐘。

## 實作細節與陷阱（修改程式前必讀）

**兩份卷子能對齊的原因**
- 所有表格固定欄寬（`tblLayout fixed`）、固定列高（`EXACTLY`）。
- 標題、間距段落用固定行高（`line_spacing_rule = EXACTLY`），空段落的段落標記字級也要設小，否則以 12pt 計高。
- 文件結尾加 0.5 mm 的極小段落，避免 Word 自動補的空段落把版面推到第二頁。
- 解答卷只能改「格子裡的文字」，不能改任何尺寸。標題、大題說明都必須維持單行。

**python-docx**
- 設了 `subscript=True` 後不可再寫 `superscript=None`（兩者共用 `w:vertAlign`，會把下標清掉）。
- 解答過長會換行並被固定列高切掉：程式依顯示寬度自動把長答案縮到 9.5pt；數字與題號之間用半形空白，不用全形空白。

**LibreOffice 轉 PDF**
- 雙欄＋連續分節＋`keepLines` 時，欄位平衡會把多行段落截成只剩第一行（文字直接消失）。→ 在填空題範圍移除 `keepLines`。
- 中文段落裡的 `____` 會被當成中文字，任兩個底線之間都能斷行。試過但無效：U+2060 word joiner、不斷行空白 NBSP（換行後會懸掛到欄外、底線消失）、U+2007、單一字元加寬字距（底線畫到欄外）。**有效做法**：在底線前插入 1pt 白色 `x`，讓底線以英文單字處理。
- **驗證缺字要用「字元計數」比對**，不要用段落文字比對：`pdftotext` 抽雙欄 PDF 時文字會左右交錯，段落比對會誤報。

**電腦檔案**
- 預覽圖、暫存檔不要寫進使用者的資料夾；在使用者電腦上刪除檔案需要先取得權限。
